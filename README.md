# 飞书文章同步助手

Chrome 浏览器插件，从飞书知识库/文档公开链接提取文章内容，并同步到 CSDN 和知乎。

## 功能特性

- 🚀 从飞书文档（wiki/docs/docx）提取文章内容
- 📝 HTML 转 Markdown 格式
- 🔄 同步到 CSDN 和知乎（保存为草稿）
- 🖼️ 自动处理图片上传
- 📜 同步历史记录
- ⚙️ 平台配置管理

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式（热更新）
pnpm dev

# 构建生产版本
pnpm build
```

## 使用说明

1. 访问飞书文档公开链接（`*.feishu.cn/wiki/*` 或 `*.feishu.cn/docs/*`）
2. 点击浏览器工具栏中的插件图标
3. 预览提取的文章内容
4. 选择目标平台（CSDN/知乎）
5. 点击同步按钮

## 支持的平台

- ✅ CSDN - 完全支持，自动上传图片并保存为草稿
- ⚠️ 知乎 - 部分支持（知乎API可能需要特殊权限或已更新）

### 平台说明

**CSDN**
- 自动登录检测（通过Cookie）
- 自动上传图片到华为云OBS
- 自动添加默认标签（如果未提供）
- 保存为草稿，支持后续编辑

**知乎**
- 需要在浏览器中登录 zhihu.com
- 图片上传可能失败（会保留原始URL）
- API可能需要额外验证或权限
- 如遇问题，建议手动复制markdown内容到知乎编辑器
